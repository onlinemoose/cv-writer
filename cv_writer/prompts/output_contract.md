# Output format

Return exactly this and nothing else:

<the tailored CV, in Markdown: the identity block, then the sections in
the order the method and the region call for>
{{SENTINEL}}
<a short note, in Markdown:
- one line per key requirement in the job posting that the CV now
  addresses — name the requirement and the role, achievement, or section
  that evidences it;
- one line for anything from the sources that was cut or de-emphasised to
  make room;
- one line for each important requirement the sources do not evidence.>

This format is fixed. No method, house style, or candidate parameter
changes it.
